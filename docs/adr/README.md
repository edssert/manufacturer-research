# 아키텍처 결정 기록 (ADR)

이 디렉터리는 되돌리기 어렵거나 여러 문서·스크립트·테스트에 동시에 영향을 주는
결정을 기록한다. 세부 실행 절차는 [SOP](../sop/)에, 검증 명령의 전체 목록은
[품질 게이트](../quality-gates.md)에 둔다.

저장소 전체 규칙의 단일 원본은 [`AGENTS.md`](../../AGENTS.md)다. ADR은 그 규칙이
왜 지금의 형태가 되었는지와 어떤 검사로 강제되는지를 설명하며, `AGENTS.md`를
대체하지 않는다.

## 작성 규칙

- 파일명은 `NNNN-kebab-case-title.md`이고 번호는 재사용하지 않는다.
- 상태는 `제안`, `채택`, `대체됨`, `폐기` 중 하나다. 결정을 뒤집을 때는 기존
  문서를 지우지 않고 새 ADR을 추가한 뒤 두 문서에 상호 링크를 남긴다.
- 모든 ADR은 **상태 · 날짜 · 맥락 · 결정 · 검토한 대안 · 결과 · 검증 · 재검토
  조건** 절을 포함한다.
- 변동 가능한 수치(제품 수, 결손 수, 중복 baseline 등)를 본문에 복제하지 않는다.
  해당 값을 관리하는 `config/*.json` 또는 `package.json`을 링크한다. 근거는
  [ADR-0003](0003-baseline-json-source-of-truth.md)에 있다.
