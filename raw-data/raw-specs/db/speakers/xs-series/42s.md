# 42S

Sources:

- d&b official product page: `https://www.dbaudio.com/global/en/products/series/xs-series/42s/`, reviewed 2026-08-18.
- d&b official datasheet 1.1: `https://www.dbaudio.com/assets/products/downloads/manuals-documentation/xs-series/dbaudio-datasheet-42s-1.1-en.pdf`, pp. 1-2, copyright 01/2026.

Passive 2-way point source; 4.5 in LF / 0.75 in HF dome tweeter; 117 dB maximum SPL; 120 x 90 deg; 77 Hz-20 kHz (-5 dB standard), 65 Hz-23 kHz (-10 dB standard, IEC60268); 75 W RMS; 128 x 220 x 150 mm; 1.6 kg. The official page specifies 8 cabinets per channel for 10D/25D/30D/40D and D20/D25/D40/D80/D90, and 4 recommended (6 maximum) for 5D/5DM.
